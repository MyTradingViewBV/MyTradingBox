## Executive summary

The fix-audit branch did what it set out to do. All P0 items from the first audit are closed in code:

- The hardcoded user-ID fallback is gone.
- The router vulnerability is gone: `npm audit` reports 0.
- A Content-Security-Policy is in place. Its hash matches the real build output and CI enforces it.
- Logout now revokes the session on the server and removes the push subscription.
- Admin requests can no longer go out without a token.

Tests grew from 824 to **897**. Coverage rose from about 48% to **about 60%** of lines. Lint enforces template rules for the first time.

Five issues stand out now, in this order:

1. **Do not deploy `fix-audit` as it is.** The live site was published today at 11:46 from `improve-chart` (version 0.2.48). That branch has 5 commits `fix-audit` lacks: the version bump, the login version fix, and three chart/MCB features. Deploying `fix-audit` would roll the site back and fork the release log. Merge `improve-chart` in first (N-OPS1).
2. **The watchlist leak still exists in the backend.** `GET api/UserSymbols/{userId}/profile` takes the user ID from the URL and never checks that it belongs to the caller. Every other action in that controller uses the token's user ID. Any logged-in user can read anyone's watchlist. Today's frontend fix removed the accidental trigger but cannot close this (N-SEC1, needs an API change).
3. **The next deploy would publish the security fixes' commit messages** in the public release notes, for example "Remove hardcoded fallback user ID" (N-OPS3).
4. **`/tv-chart` is OnPush without knowing it.** Angular 22 made OnPush the default, and this page declares no strategy and never calls `markForCheck`. Its spinner and dropdowns can stay stale after data loads. The bug was already there before today (N-CQ1).
5. **The shared `*.github.io` origin** undermines both CSP `'self'` and localStorage isolation. Any other GitHub Pages site under the same account can read the stored JWT. Clickjacking also can't be prevented without headers (N-SEC2, N-SEC3).
